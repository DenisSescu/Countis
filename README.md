# Countis 💰

A personal finance Android app built with React Native + Expo.

## Features

- 🤖 **AI Predictions** — personalized spending analysis powered by Claude AI
- 🔄 **Recurring Transactions** — automatic monthly generation
- 🎯 **Savings Goals** — with monthly auto-contribution
- 💰 **Category Budgets** — monthly limits with visual alerts
- 📊 **Detailed Analytics** — donut charts and 6-month trend
- ⏳ **Salary Countdown** — available balance and daily budget
- 💱 **Currency Conversion** — RON, EUR, USD, GBP (live ECB rates)
- 🌙 **3 Themes** — Default, Pink, Dark

## Tech Stack

- React Native + Expo SDK 54
- TypeScript
- SQLite (expo-sqlite) — local storage
- Supabase Edge Functions
- Claude API (Anthropic)
- Frankfurter API — live exchange rates
